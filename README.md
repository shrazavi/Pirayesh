# Pirayesh – Salon Booking & Scheduling Platform

A service booking platform designed for barbershops and beauty salons, enabling customers to schedule appointments while helping businesses manage their availability and daily operations more efficiently.

## Overview

Pirayesh was built as a startup-oriented MVP to address one of the most common challenges in personal care businesses: manual appointment management.

The project focused on simplifying the booking experience for customers while providing salon owners with better control over schedules, availability, and client interactions.

This project gave me hands-on experience in validating product ideas, balancing business requirements with technical constraints, and delivering an end-to-end solution within a limited timeframe.

---

## Features

- User authentication and registration
- Customer and salon owner roles
- Appointment booking system
- Availability and time-slot management
- Booking status tracking
- Administrative workflows
- Backend APIs for business logic
- Responsive and user-friendly experience
- MVP-oriented product architecture

## Architecture

The platform follows a client-server architecture:

Android Client
↓
REST API (Node.js + Express)
↓
MongoDB Database
